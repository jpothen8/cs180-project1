Single-scale alignment

NCC and L2 · search ±15 pixels · scoring border 15%

A and B are the reference and shifted patches over the same interior pixels Ω. μ A and μ B are their means; N is the number of pixels.

L2 distance

L2(A, B) = √ ∑ p∈Ω (A p − B p ) 2

Minimize L2. Code score: −L2²/N (maximize).

Normalized cross-correlation

NCC(A, B) = ∑ p∈Ω (A p − μ A )(B p − μ B ) √ ∑ p∈Ω (A p − μ A ) 2 √ ∑ p∈Ω (B p − μ B ) 2

Maximize NCC.
